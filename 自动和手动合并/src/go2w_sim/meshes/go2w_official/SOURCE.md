# Go2-W visual meshes

The mesh files in this directory were copied without geometry changes from:

https://github.com/unitreerobotics/unitree_ros/tree/master/robots/go2w_description/dae

They are used for visual rendering only. `go2w_sim` keeps primitive collision
geometry and its existing inertial/dynamics configuration so the detailed and
stick variants can be compared under the same simulator control conditions.

The files were downloaded directly from the Unitree Robotics organization.
Their SHA-256 hashes were checked against the previously tested mesh set and
all eight geometry files were byte-for-byte identical.
